# TS033 → TS034: two additional runs per condition

Four fresh TS034 target games completed: two session and two answer-only. All four reuse the same TS033 source trajectory and revealed answer from Set 2 round 2, so they are conditional repeats rather than independent source samples. Each target had a fresh 100-submission budget. TS034 used Host v13 and scoring v5.

The copied source directory preserves provenance; its calls are historical and must not be counted again as new spending. The trajectories include user-authorized format re-prompts and network recoveries; malformed outputs did not consume submissions and replayed requests may incur duplicate remote charges. The final session game enabled automatic re-prompts for multiple QUESTION blocks, with a limit of three per submission. Frozen inputs, target results, token records and compressed API audits are included.
