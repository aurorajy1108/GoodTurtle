# 数据入口

- 当前完整题库/评分：`annotations/turtle50_v4/private.json`（50题、161评分点）。private指对player保密。
- 人工参考问答：[host_reference/README.md](host_reference/README.md)，新上传只进inbox。
- 当前Host示例：[host_packs/README.md](host_packs/README.md)，active包由绑定表选择。
- `annotations/turtle50_v2/`、`turtle50_v3/`：历史版本，复现时按原run快照。
- `public/`、`host_dev/`、`release_scope.json`：早期原型兼容资料，不是当前50题主入口。

`runs/`存模型实验结果；人工reference不放那里。题库、Host私有输入和人工答案不得发送给player。
