# Trajectory review records

AI review, not human gold. `question_reviews.jsonl.gz` contains all 12,631 reviewed submissions with original questions/labels and review reasons. `review_questions_only.csv` is the human-check shortlist. Coverage, inventory and statistics preserve their original audit scope. Old paths inside these immutable records are historical provenance; resolve them with `python scripts/results_catalog.py locate OLD_PATH`.

The full interactive review dashboard and duplicate per-game copies remain on `archive/full-repository-20261114`.
