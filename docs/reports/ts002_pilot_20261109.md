# TS002 solo and free-dialogue pilot, 9 November 2026

This exploratory pilot used one independent game per strategy, frozen code at `27091a3`, the same TS002 puzzle and host-v9 binding, coverage-v2 grading, DeepSeek Flash players, DeepSeek V4 Pro host and grader, and a budget of 100 submissions per game. It is not sufficient to estimate a strategy effect. The later host-v10 and TS002 v7 scoring dataset are different experimental conditions; do not pool their results with this pilot.

| Strategy | Questions | Finals | Final score | Best score | Outcome |
| --- | ---: | ---: | ---: | ---: | --- |
| Free dialogue | 73 | 27 | 30% | 50% | Budget exhausted; unsolved |
| Solo | 99 | 1 | 0% | 0% | Budget exhausted; unsolved |

In both games, the final forced submission reached the grader. Free dialogue generated 53 malformed responses that were successfully corrected after one additional generation each, plus 34 local format recoveries. Solo encountered four confirmed pre-send TLS handshake failures; safe retries allowed the game to finish. Each game has only one sample, and the format-correction protocol itself can affect trajectories.

Manual review found potentially misleading host answers in the free-dialogue game about human-bone ornamentation and stuffing (submissions 18, 22 and 25), which are not established by the reference story. In the solo game, a compound question about a severed head or another body part received `yes`: that does not confirm the head, but the later trajectory pursued that interpretation. These observations limit attribution of the scores to player strategy. Grader checks found the free-dialogue 50% answer and the solo 0% answer broadly consistent with the then-current rubric; the old C1 identity wording was ambiguous. Scores remain original model outputs.

Provider-reported usage was 13,120,478 input tokens (12,911,488 cached) and 191,751 output tokens for free dialogue, and 2,426,956 recorded input tokens (2,371,072 cached) and 57,091 recorded output tokens for solo. Four failed solo attempts had no token usage. These counts are not actual billed costs; pricing was unknown in the run's snapshot.

## Reproducing the revised setup

`data/studies/ts002_v7.json` is a TS002-only dataset: C1 full credit requires the hand to belong to the boyfriend or romantic partner, and the completion requirement identifies the same person. It is paired with the active host-v10 binding. This is a new version; it does not rewrite pilot scores. The grader's uncertainty guidance and optional coverage metadata normalization are offline-tested, but have not been verified in new model calls. Tests with the exact six host examples passed 18/18; these are not held-out paraphrases.

```sh
python3 scripts/study_20261102.py \
  --dataset data/studies/ts002_v7.json \
  --config configs/loop.deepseek.solo-json.json \
  --suite team --team-puzzles TS002 --strategies solo,free_dialogue \
  --repeat 1 --mode dry-run --out /tmp/ts002-v7-preflight
```

Change `--mode dry-run` to `--mode run` and use a new output directory only when ready to make paid model calls. Store API credentials separately; never commit them.
