# 本地监督、断点恢复与通知

监督器每30秒检查本机实验，已支持的故障校验通过后自动创建续跑副本，
并使用Mac桌面通知和`alerts.jsonl`记录检测、恢复、完成及需要处理的状态。
不需要反复发送“检查进度”才能检测停止。

它是本地程序，不会在当前ChatGPT对话里主动发送消息；没有配置微信、邮件或第三方通知。
Mac必须开机、联网且当前运行环境可用。通知命令成功不保证弹窗可见，系统通知权限和专注模式仍会影响显示。
启动脚本使用caffeinate防止运行期间空闲睡眠，不保证合盖或关机后继续。
本机尝试launchd服务时被macOS隐私保护拦截访问Desktop项目目录，服务已撤销；
当前使用有项目访问权限的持续执行环境，不声称已经安装了开机自动启动服务。

## 当前批次

原25局任务仍为`cl-set1-a`与`mas-ts038-a`，没有新增重复或重新解前题。
原始失败档案不修改；续跑副本保留全部API日志、已完成局、公开反馈、角色会话和额度。
CL从58次提交继续；MAS先从68推进到70，第二次校验继续保留70次提交及未完成的格式纠正请求。

```bash
bash scripts/run_supervised_campaign.sh STOPPED_CAMPAIGN_OR_SUPERVISOR NEW_OUT
```

第二参数必须是新目录。第一参数可为原campaign，或已停止的监督器目录；
后者选择每个槽最新的有效study，保留之前的恢复记录。拒绝接管仍有活跃工作的运行。
密钥从已export的环境读取，未设置时读取Git忽略的`.env.local`，不写入命令行或日志。
同一个原campaign持有独占锁，避免两个监督器重复收费。

Python所有参数：

| 参数 | 默认 | 意义 |
| --- | --- | --- |
| --campaign | 必填 | 已停止campaign或监督器目录 |
| --out | 必填 | 新监督目录，拒绝覆盖 |
| --interval | 30 | 检查间隔，1–60秒 |
| --cooldown | 60 | 运行再次失败后的恢复等待，按次数倍增 |
| --max-recoveries | 3 | 本次监督每槽最多启动的恢复子进程数，1–10；先前监督次数另外保留 |
| --stall-seconds | 2700 | 长时间无API日志时告警阈值，至少60秒；不强杀可能仍在生成的请求 |
| --notify | macos | macos发送桌面通知；none仅记录本地告警 |

## 自动恢复范围

- DeepSeek在明确发出HTTP请求前发生的TLS/DNS等失败：恢复原角色消息链，只重发同一请求。
- 已明确中断、没有任何已观察答复的请求：显式恢复，记录可能重复远端收费；不记作免费请求。
- MAS同时恢复两个独立会话、共享聊天、下一位speaker、内部讨论次数和格式纠正重试序号。
- 已有的有限Player格式、明确保存动作、无类型输出纠正、Grader纯说明元数据修复仍需各自校验。
- CL原A前缀仅允许API落盘新增的顶层timestamp不同。正文、请求、角色、顺序、答案揭晓和新额度必须一致；继续保留原检查点与哈希。

恢复前完整校验会话链、原请求与轨迹，调用前再核对请求body逐字一致。
有任何已观察模型答案，不能当作空请求重新抽样。恢复后观察到新答复才记录“已恢复运行”。
同一个未变化的失败检查点只修复一次，不无限循环。API、模型、Host或评分标准不会被自动替换。

认证/余额、截断、拒绝、评分冲突、无法定位的矛盾、无法验证的断点均暂停并通知。
低分、未解出或耗尽100次不是基础设施错误，不触发重跑。
监督器不自行调用Codex改任意代码或改标准答案；需要新代码修复的异常由告警交给开发者处理。

独立槽之间不再因一个失败而取消另一个。已冻结的工作可在仓库出现代码更新时继续运行，
但监督器暂停启动新的修复，直到新控制器被验证。主动中断运行不会被自动撤销。

## 输出、费用与验收

`index.html`显示最新归档中的对局；`status.json`给出各槽、尝试、PID和告警状态；
`alerts.jsonl`保留通知请求及命令是否成功。`continuations/<task>/attempt_XX/`是独立恢复档案。
费用只统计每槽**最新**归档一次（它已包含旧调用），Host门禁费用只计一次；
缺失usage的调用保持未知。不要把原campaign和多个恢复副本费用直接相加。

验证包括实际58/70问断点的完整实验入口拦截检查（未发API），
确认首个请求逐字一致；合成测试覆盖网络恢复、双agent Host待答、
格式纠正中断、前缀时间戳兼容、篡改拒绝、独立槽完成、有限重试和未知错误告警。

运行监督器本身不调用LLM；实验和已有格式辅助调用按原配置计费。
官方文档同样区分工作调度与应用通知；本实现没有创建云端调度任务：
[OpenAI scheduled automations](https://developers.openai.com/api/docs/guides/agents-api/sessions/automations)。
