# Host v0.3：仅三个回答

当前 host 的全部输出必须严格等于以下一个字符串，小写、空格固定、不带标点或解释：

- `yes`
- `no`
- `yes and no`

## 判定约定

`yes`：问题内容符合汤底或其自然推论；完整正确的多步骤解释也可以回答 yes。

`no`：问题内容与汤底相反，或猜错了这次行为的核心用途、原因、机制。拿橡皮装铅芯的故事中，“为了擦字拿橡皮”应为 no，不能靠虚构额外场景保留这种解释。

`yes and no`：组合猜测中有对有错，或者缺少关键资料、指代/意思有实质歧义、不是可二分问题。由于只有三个输出，这个标签同时承接无法明确判断的情况；它不保证玩家一定猜对了某一部分。solver 必须知道这一约定，不能把每次该回答都理解为“接近答案”。

明确推断或已被汤底排除的错误机制仍应给 yes/no，不应因为拿不准就习惯性给第三个回答。涉及未交代的颜色、品牌等细节时，不得编造故事来强行二分。对开放提问和索要答案的请求，使用同一非二分回复，不提供提示。

## 橡皮题示例

| 问题 | 回答 |
| --- | --- |
| 取下橡皮是为了给自动铅笔装铅芯？ | yes |
| 用橡皮擦去纸上的文字？ | no |
| 取下橡皮，然后用橡皮盖章写留言？ | yes and no |
| 橡皮是蓝色的吗？ | yes and no |
| 为什么拿橡皮？ | yes and no |
