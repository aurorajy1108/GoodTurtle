先在启动终端export自己的`DEEPSEEK_API_KEY`，或执行`source .env.local`；key文件不入Git。以下是真实收费实验，请使用新的输出目录并只选择自己负责的任务：

```bash

```

smoke为4局CL＋2局MAS；formal为21局CL＋4局MAS，每条件两次。其他同事替换runner和task IDs，见[团队分工与每个参数](../../running/team_campaign_20261111.md)。计算预算匹配的四组MAS自查是[另一套方案](../../running/compute_matched_agents.md)，不要混成同一实验。

仅准备计划、核对冻结输入，不调用API：

```bash
python3.11 scripts/team_campaign.py start --preset smoke \
  --runner preflight --tasks cl-set1-a,mas-ts038-a \
  --mode plan --out runs/api/main_preflight_yourname
```

`--runner`只记录执行人；`--tasks`选择明确的人工槽；`--mode plan`冻结输入而不运行；`--out`必须是新目录。检查输出的`tasks/<task-id>/runtime_snapshot/data/dataset.json`，其中每题的`grading_protocol`应为`coverage-v3-unified`，`configs/run.json`记录实际模型参数，`snapshot_hashes.json`记录冻结文件哈希。
