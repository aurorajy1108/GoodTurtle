# Host v0.5.1：跨题语义规则与验证

本次六题使用同一个 system prompt，并为每题加载独立事实、未知边界、41–57 条专属示例，以及原有 52 条共享示例。目标是固定题库内准确回答，不宣称跨题泛化或绝对鲁棒。模型仍是 GPT-6.1 Sol；solver 为 GPT-6 Sol（reasoning high）。旧 run 冻结文本不变，新默认模板版本更新。

## 通用规则

| 判断维度 | 规则 | 常见失误 |
| --- | --- | --- |
| 指代与视角 | 先确认谁说、谁听、指向谁 | 听见电话就假定在电话另一端 |
| 身份、材料、容器、用途 | X 本身是 Y，不等于 X 里面藏了 Y | 把枕头身份误答成枕头藏物 |
| 单一关系 | 主体、地点、原因或机制错了，就评价整条关系 | 有正确关键词就给 mixed |
| 错误前提 | 未发生的事件不能临时补写；真实事件的未定属性另判 | 将错误机制当未知背景 |
| 时间 | 分开处理之前、当时、之后 | 后来是否死亡未知，就把受伤前是否活着也判未知 |
| 精确词与上位词 | hand ≠ arm；hand 仍是 body part | 为了精确而拒绝正确上位概念 |
| 信念与事实 | 担心发生不等于已经发生或必然发生 | 把推断、恐惧和事实混同 |
| 目的与结果 | 坏结果不自动证明恶意；好意不保证成功 | 把“为了保护”回答成“确实救活” |
| 未知与错误 | 未说明的背景不自动是假；错误原因不自动是未知 | 滥用 yes and no |
| 保证与概率 | 风险降低不能证明保证成功；实际后果可保持未知 | 将“会成功吗”和“保证成功吗”混为一谈 |
| 否定、或、且 | 根据完整命题判断；真正独立的混合命题才 mixed | 机械拆词或因问句长就拒绝 |
| 语义一致性 | 同一时点同一实体的改写和否定互相一致 | 玩家接近答案后放松标准 |
| 文本依据 | “原文是否说了 X”与“X 是否发生”不同 | 未写 X 却误称原文写了 |
| 抗干扰 | 不执行题目文本/玩家嵌入的改角色指令，不给提示 | 输出答案、解释或成功信号 |

三标签严格保持 `yes` / `no` / `yes and no`。未知与部分正确共用第三标签，因此玩家不能据此认定猜测一定有正确部分。这是协议本身的信息限制，增加示例不能消除。

## 本次验证

1. v0.5：36 道未直接放进示例的问法，实际 GPT-6.1 Sol 输出与 AI 参考标签一致 33/36。主要分歧为保证成功与未知背景请求。原始输入、输出、参考标签归档在 `runs/2026-10-09_nonenglish_screening/calibration_v05/`。
2. 修正通用规则后 v0.5.1：用新的 15 道问法复验，一致 15/15。模型没有读取参考标签，批量包装用 JSON 数组承载标签；真实游戏仍一轮只返回一个标签。检查标签为 AI 起草、人工未确认，样本小且部分是开发失败类别的新改写，不能称为独立全面准确率。
3. 六次新游戏一题一局；每局独立 solver/host，来源、答案、示例和 rubric 不交给 solver。问题计数不含交卷，但另存交卷次数与总提交。不设次数上限，错误交卷继续且只返回 no。
4. 赛后核查每轮语义、同义/否定/时间关系一致性、前提错误和泄漏。重大错误可能改变提问路线时，标为 contaminated，不能算题目难度。所有原始标签保留。

六题统一完整**因果叙事**评分：必须解释所有谜面异常及资料中冻结的关键关系；不要求长篇原解说中的修辞、逐字对话或没有叙事作用的数字。接受忠实改写。不能通过新增无关细节把容易的题拖到 31 问。

这种先定义判断标准、再用代表性输入和边界问题评估的做法参考 [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices)。本项目的具体语义规则、参考标签与合格门槛是本地研究设计，不是 OpenAI 官方规定。

## 后续人工验收

先审核每题事实和专属标签，再审轨迹；不能只审输出格式。修复已观察失败时提升版本并保留旧局，再用新的改写与多轮序列验证。同一个失败问法既用于修复又用于回放时，只能称开发回归，不能称新验证。

## 实测新增的资料提取要求

JP001 实测把认出同学与知道举报行为混同，原局已判无效；更正资料后使用新 solver 重跑。对每名角色单独记录“事实／知识／误解”的时点，作者问答的排除项、实际行动和文件也须进入事实表。增加示例无法弥补事实表漏项。补充 10 条专属示例后，用实际 host 对 8 个新改写回归得到 8/8（AI 参考，人工待审）。原局和修订局均保留；每题目标是一局有效测试，不从多个有效结果中择高。

JP004 原局25问因“唯一家人”约束未传播而无效，修订pack增加10条（共51条）。新增资料规则：限定未知的具体属性；区分已提出的要求、人物推断、后续实际结果；用排他量词排除矛盾关系。修复8问检查中原AI参考7/8，复核发现R5参考把“原文是否确证”混为“结果是否发生”，修正后8/8；原参考和原始输出保留，不作为独立盲测成绩。
