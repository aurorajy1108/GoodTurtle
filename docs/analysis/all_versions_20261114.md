## 二、CL：整体没有稳定的完整成功提升，但有可解释的局部迁移

所有分数都是原始末卷partial score。以下表的旧、新标签指实际冻结协议，不依据现在README反推旧实验。

|本机Set1，新统一评分|37.50%（12局）|46.25%（12局）|27.50%（12局）|答案摘要比完整会话更有利的描述性结果|

### Set1 的相关经验确实改变了搜索方向

|前题 → TS013|关系假设|直接B，n=4|答案，n=4|会话，n=4|
|---|---|---:|---:|---:|
|TS015 → TS013|positive|36.25%|56.25%|45.00%|
|TS014 → TS013|negative|40.00%|33.75%|6.25%|
|TS028 → TS013|irrelevant|36.25%|48.75%|31.25%|

TS015 的course双关让玩家更容易质疑“课程”这一默认含义。会话条件四局分别Q2/7/2/2就确认菜品，但仍没补齐厌恶口味、本人请求逐道清走剩食、选餐截止等叙事。这是**词义层的迁移成功，与完整因果重建失败并存**。

另一面，TS014的学科叙事可能强化错误搜索方向。某会话局Q50错误/过宽肯定遮屏后，接近后半50问都围绕屏幕、视力、账号；另一些局即使确认菜品，仍反复用吃光或例行清盘替代真正的主动拒食。完整会话携带的不仅是经验，还有先前猜测和搜索惯性。

### Set2 的预设关系不能直接等同于实验效果

v17中，TS033 negative的答案条件均分66.5%，反而高于55.5%的公共基线；TS035 positive的答案条件只有23%。同是TS033，session又降到27%。这表明**内容如何呈现、玩家是否重检角色，比positive/negative标签本身更直接地影响轨迹**。这些是候选解释，不是本设计已经隔离的因素。

TS033与TS034都有绑架，角色正好翻转，理论上既可能误导，也可能提醒检查“父亲本人是不是人质”。TS035与TS034主要共享父亲担忧他人受害这一抽象主题，题面与具体机制较远，不能期待一定帮助。

### 最新T22提供一个更强、也更有意思的检验

|TS022条件|n|末卷均分|相对baseline|完整成功|
|---|---:|---:|---:|---:|
|baseline|5|26%|—|0/5|
|先做TS047，positive|5|27%|+1个百分点|0/5|
|先做TS045，negative|5|21%|−5个百分点|0/5|
|先做TS019，irrelevant|5|28%|+2个百分点|0/5|

TS047与TS022都依赖“画像其实是窗户，脸是窗外真人”的核心反转；正相关的机制联系比泛主题更强。归档元数据记录A答案已揭示、五个B复用同一个A前缀。不过四个positive末卷仍缺画像误认，只有一份接近核心（75%）。读取各局最初十问也没有看到立即原子检验“画像=窗户”的策略。

这组结果可写成：**拥有一个高度相关的先例，并不保证弱玩家能提取并主动复用它的核心机制。** 不能仅凭27%对26%就确认关系无效，也不能在缺少原始完整请求body的便携发布包上宣称已独立证明供应商处理了每条继承内容；实际发送的完整请求需回原机器审计。当前可以确认固定前缀和答案揭示的归档链。

## 三、MAS：有若干正向现象，尚未形成一致优势

|题目/批次|单agent|双agent|双agent减单agent|成功数|
|---|---:|---:|---:|---|
|TS038 April旧版，各4局|87.5%|62.5%|−25个百分点|2/4 vs 2/4|
|TS038本机v14，各4局|25.0%|52.5%|+27.5个百分点|0/4 vs 1/4|
|TS022，各5局|26.0%|36.0%|+10个百分点|0/5 vs 1/5|
|TS042，单agent仅1局/双agent5局|50.0%|63.0%|+13个百分点|0/1 vs 0/5|

T22 baseline同时用于CL和MAS比较，但在档案总数中只计一次。TS042的单次baseline不足估计稳定的基线分布。不能取四行差值的简单平均，声称MAS具有一个跨题通用提升。

尽管如此，有价值的观察是：**三组均分出现正向差值，另有一组反向；两个不同题目的MAS各出现一个完整成功，而对应本批单agent没有。** 这可以作为进一步研究动机，措辞应是“局部、题目依赖、变异很大”，不要写成已证实普遍优越。

成功案例中，两名agent会从不同角度建立笔迹、伪造、谋杀等事实，或纠正“实际作者/名义作者”的混淆；失败案例中，两人也会共同接受错误角色、把OR的yes收窄到自己偏爱的例子，继续在同一个错误框架中花费几十问。**共享对话使信息传播更快，也使错误假设传播更快。**

### 自查对照提示：额外思考可能有用，但不是免费收益

本机TS038四条件均分：solo25%、solo_review81.25%、MAS52.5%、MAS_review41.67%（最后条件仅3局完成）。solver平均输出token约5,487、50,300、14,621、74,982。预算上限相同，实际消耗不同；单agent自查实际输出是普通单agent约9.17倍。不能把81.25%的全部增幅归给某一种认知机制。

双agent自查输出消耗大，在81–84次外部提交就因输出额度触顶而最终交卷。自查可能改善反省，也可能压缩向Host获取新信息的机会。前两次solo_review成功，后两次不成功，且controller/recovery有差异，不能只选择前两次报告。

## 四、不要把“未满分”一律解释成没找到谜底机制

新TS042尤其值得在报告中说明。baseline的末卷已经明确：苹果放头上、鞋让她增高、飞刀按旧高度投掷、刀击中头部。但原评分只有50%，分别因为缺少circus、few centimeters、male partner三个修饰点，三项都给半分。MAS第5局写齐circus与苹果，85%仍因没明确few centimeters被扣分。

为帮助解读，另作**事后AI机制审阅，绝不替代原评分或用于宣称正式成功率**：检查四个明确事实——①苹果在头上的飞刀表演；②高跟鞋增高；③投掷未按新高度调整；④刀击头致死。baseline和MAS r02/r03/r05都明确覆盖四点；MAS r01否定增高因果，r04缺苹果。详见 [TS042机制补充](https://huggingface.co/datasets/COMP1110-20261A-Group50/GoodTurtle-experiments)。

这说明TS042的大部分分数差异不全是核心诡计差异，也有完整叙事细节覆盖差异。baseline本身已恢复核心，故63%对50%不能直接写成“MAS才学会了高度机制”。同样，TS038的wife/spouse和叙述者性别边界，也会影响严格分数。现在保留原分、披露评分要求，比临近提交偷偷重定义成功更可靠。

旧coverage-v2还存在分点评分与独立完成要求分离：9次评分1.0却complete=false，涉及3局。新的统一评分没有因此失效，旧记录也不能按新规则事后自动截在第一次1.0。完整叙事重建是原研究设定，机制审阅只是补充解释。

## 五、可以直接用于结论的findings

1. **迁移首先发生在假设优先级层面。** 相关先例能加速词义突破，但完整因果链和全部叙事仍可能失败。
2. **更多上下文不是单调更好。** 长对话带来的搜索惯性、早期Host误导与冗余猜测，可能抵消相关答案的收益；Set1摘要条件高于完整会话是具体实例。
3. **两个agent的收益依赖实际互补与纠错。** 个别成功案例支持这一机制，失败案例则显示共同固化和重复枚举。两个角色名字不是有效合作的充分证据。
4. **自查与外部探索存在预算分配取舍。** 普通单agent与自查差异不能只用“agent数量”解释，应同时列实际token/调用和额度停止原因。
5. **严格叙事分数、核心机制发现、完整成功是不同观察维度。** 原实验保持统一定义；分析中解释为何机制已找对却未满分，能避免把所有失败都归给推理不足。
6. **误解的累积比单问错误更能解释部分高变异。** 一个错误身份或对复合问的过推，可以导致后几十问锁定错误分支。只增加重复数不能消除这种系统性路径。

**不适合写的结论：** “CL普遍有效”“negative必然负迁移”“MAS稳定优于单agent”“自查严格同计算量获胜”“Host已达到人工金标准准确率”。

**适合写的结论：** “在探索性实验中，相关先例与多agent合作改变了搜索行为，并在部分题目改善partial reconstruction；完整解答仍不稳定。轨迹显示，早期语义误解、假设固化、共享信息中的错误传播，以及完整叙事要求，是当前表现的主要限制。”

## 六、deadline前的报告组织方式

主文保留Set1/Set2/Set3与MAS三道题的条件表，清楚标n、末卷均分±SD、严格成功数。把版本作为表格脚注/方法说明，不必让全文变成版本变更流水账。选“TS015快速识别course”“TS022同构先例未主动复用”“TS038协作纠正作者身份”“TS042核心机制与严格分数不同”四个案例支撑讨论。

附录提供全部逐局CSV、HTML轨迹和冻结设置；旧探索、技术中断、早期无控制session单列。将本项目称为**上下文经验迁移（continual in-context transfer）**，因为没有更新模型权重。limitations简短交代小样本、固定A、Host/Grader版本与评分边界、MAS额外实际计算量；这些限定结论范围，不会使已经完成的工程与实验失去价值。

本机未完成的r04_mas_review保持36次提交的断点，没有当成0分。现阶段可直接以已完成数据写报告；无需为了凑四次而掩盖中断，也无需再花API把全部新版补跑完。
