## 基础设施判断

15 个已完成局均通过代码现有发布审计（counter、score arithmetic、角色会话及成本链等），但这不能验证每句自然语言的准确性。QUESTION body 接受多个问题、改口、自带 `<CoT>`、伪 user/context_update，类型解析成功不等于内容规范。一些发给队友的提议被当外部 QUESTION，既消耗额度又收到与本意不符的反馈。thinking disabled 也不能阻止玩家把推理写进普通 text。self handoff 可让一名 agent 连续主持，不能从两个角色标签推断实际互补探索。

原 r04 两次不明响应的人工授权恢复已标记可能重复生成/计费，未知部分在原额度内预留。后来又发生的新断流没有冒充此前授权自动消费。完整问题级疑点在每局 `.review.jsonl`，所有 `human_confirmed=false`。这些是审阅线索，不是新的人工 gold，也不是可直接当真值计算的 Host 错误率。
